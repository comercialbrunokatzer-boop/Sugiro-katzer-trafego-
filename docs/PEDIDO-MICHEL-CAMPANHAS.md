## Por que cada coluna importa (pra ele entender o pedido)

- **Gasto + leads** → custo por lead, e se a campanha traz comprador ou só volume.
- **Gasto + venda** (já tenho as vendas) → **custo por VENDA**, o número-alvo.
- **Tempo que rodou** → separar "vendeu pouco porque é ruim" de "vendeu pouco
  porque rodou 3 dias".
- **Ativa/pausada** → não adianta eu mandar "escalar" uma campanha que já parou.
- **Campanhas com 0 venda** → é o único jeito de achar **onde cortar**. A base de
  vendas não mostra essas (elas não têm venda), então só o Michel trazendo a lista
  completa.
